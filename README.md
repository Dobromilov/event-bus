# Beauty Salon Event Bus API

## Описание проекта

Beauty Salon Event Bus API — это REST API сервис, разработанный на языке Go.

Проект моделирует работу салона красоты. Клиенты могут записываться на различные услуги, а система хранит записи и отслеживает состояние обслуживания.

В качестве основной идеи используется EventBus, который выступает центральным компонентом обработки событий и управления записями клиентов.

---

## Возможности MVP

Реализованные функции:

* создание записи клиента;
* получение списка записей;
* получение записи по идентификатору;
* завершение обслуживания клиента;
* Swagger-документация API;
* хранение данных в памяти приложения;
* unit-тесты для бизнес-логики и слоя хранения данных.

Не входят в MVP:

* авторизация пользователей;
* постоянное хранение данных;
* интеграция с внешними сервисами;
* уведомления клиентов;
* полноценная система очередей сообщений.

## Архитектура проекта

Проект разделён на несколько логических слоёв:

```text
cmd/
└── app/
    └── main.go

internal/
├── config
├── httpserver
├── models
├── service
└── storage
```

### Назначение слоёв

* `main` — точка входа приложения;
* `config` — загрузка конфигурации;
* `httpserver` — HTTP-обработчики и маршруты;
* `models` — структуры данных;
* `service` — бизнес-логика и EventBus;
* `storage` — хранение данных в памяти.

## REST API

### Создание записи

```http
POST /appointments
```

Пример запроса:

```json
{
  "client": "Анна",
  "service": "hair"
}
```

### Получение списка записей

```http
GET /appointments
```

### Получение записи по ID

```http
GET /appointments/{id}
```

### Завершение обслуживания

```http
POST /appointments/{id}/complete
```
